STATE SEMANTICS

Keep helper connection state separate from saved snapshot availability and age.
A stopped helper does not invalidate readable saved data. Account lock state is
also independent. Show the last successful snapshot time beside its status.

Keep “needs a login” and “bank not recorded” as separate warnings with separate
actions. Their sets can overlap; do not add the counts or imply one resolves the
other. A bank snapshot requires the relevant bank to have been opened in-game.

Use null/unknown distinctly from a recorded zero. Missing currency or reward
data should say “Not recorded”, never imply a zero balance or an unclaimed gift.
Sum account-scoped currencies once per stable account identity, not once per
character. Selection and filtered totals must state their scope. Character
selection should only narrow Bank after an explicit, visible scope choice.

Daily reset follows Europe/Berlin midnight, displayed in the user's local time.
A calendar rollover indicates a new reward day; it does not prove eligibility
or a claimable reward. Preserve the existing authenticated collection flow,
opt-in automation default, redeemed-page confirmation, manual-collection record,
and unambiguous matching level-100-or-higher snapshot requirement. Distinguish a
successful collection from a failed local record. Preserve start/stop, auto-start
and terminal restart behaviour described in popup-notes.txt.

TERMINAL ADDENDUM — REVISION 02

The added terminal.html/css/js is an interactive design simulation with one
interpreter and renderer used for both presentation modes. index.html embeds
the same core for its Terminal destination. Do not ship this demo interpreter
or its iframe wrapper as the production command implementation.

The reviewed web command bridge launches a fresh one-shot PowerShell process;
it does not execute within the live watcher. The native helper owns session
state and live updates. Real parity requires shared authoritative command
handling, live-helper dispatch and structured bounded responses in addition
to the visual redesign. See TERMINAL-DESIGN-NOTES.txt for the source-backed
contract and OPUS-5.5-IMPLEMENTATION-PROMPT.txt for the complete implementation
brief. Both source directories and newer working-branch functionality matter.

Native-window mode is a browser-rendered design of the intended console
experience. Real Windows PowerShell line editing, resizing, liveness and
shutdown need implementation and smoke testing in the actual Windows host.
