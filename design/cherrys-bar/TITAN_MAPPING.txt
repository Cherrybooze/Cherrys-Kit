TITAN PANEL 9.3.5 ARTWORK MAPPING

All source paths below are relative to the uploaded addon's archive root.
All destination paths are relative to this artwork pack's root. These are
suggested counterparts, not files automatically patched or installed.

Use the TGA files for the proposed game integration. PNG copies with the same
names are provided in PNG/ for preview and reuse. A path in your addon code
must point to the actual installed location, not to the ZIP or this document.

1. PANEL SKINS

For each source skin, Titan constructs these extensionless names:

  <skin path>/TitanPanelBackgroundTop0
  <skin path>/TitanPanelBackgroundBottom0

The new pack supplies six separate custom-skin folders:

  Titan/Artwork/Custom/StudioIronstone/
  Titan/Artwork/Custom/StudioBlacksteel/
  Titan/Artwork/Custom/StudioFroststeel/
  Titan/Artwork/Custom/StudioDarkwood/
  Titan/Artwork/Custom/StudioVerdant/
  Titan/Artwork/Custom/StudioArcane/

Each contains TitanPanelBackgroundTop0.tga and
TitanPanelBackgroundBottom0.tga, both 256 x 32 RGBA. Register a folder through
"Skins - Custom" as described in README.txt. These are additional themes;
there is no automatic one-to-one replacement of the 21 supplied skin sets.

The runtime selects Top for top-positioned bars and Bottom for bottom bars.
It does not automatically flip one file to create the other. Set_Skin in
Titan/Titan.lua requests horizontal and vertical repetition and applies the
configured alpha. Nominal bar height is 24 px in Titan/TitanGlobal.lua.

3. VOLUME STATES

Use the 32 x 16 exports to retain the original plugin's canvas and display
ratio. All four files share the same framing.

  TitanVolume/Artwork/TitanVolumeMute.tga
    -> TGA/Volume/32x16/VolumeMute.tga

  TitanVolume/Artwork/TitanVolumeLow.tga
    -> TGA/Volume/32x16/VolumeLow.tga

  TitanVolume/Artwork/TitanVolumeMedium.tga
    -> TGA/Volume/32x16/VolumeMedium.tga

  TitanVolume/Artwork/TitanVolumeHigh.tga
    -> TGA/Volume/32x16/VolumeHigh.tga

In the supplied code, muted or zero volume selects Mute; a nonzero volume
below 0.33 selects Low; below 0.66 selects Medium; otherwise High is used.
The files supply artwork only; the consuming plugin selects the state.

  Titan/Artwork/TitanPanelPushpinIn.tga

    -> TGA/Controls/16/PinIn.tga

controls. No direct bundled artwork replacement is assigned to them here.

6. PATH AND FORMAT NOTES

The supplied Lua frequently omits filename extensions in texture references.
Map references to the newly installed TGA paths deliberately; leaving old
BLP and new TGA files under an identical basename is not part of this pack's
installation instructions. Renaming or changing a path is an integration
choice for the consuming addon, not a behavior performed by these assets.

The skin names and directory structure follow the uploaded version's code.
The status/control mappings describe functional counterparts and do not
claim pixel-identical geometry, matching faction marks, automatic plugin
support, or successful testing in a running game client.
