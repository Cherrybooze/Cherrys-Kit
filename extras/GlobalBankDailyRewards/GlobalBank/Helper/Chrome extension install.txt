Global Bank Daily Rewards - Windows + Google Chrome installation

YOU NEED: Cherry's Kit with Global Bank, Google Chrome, and the separate Daily Rewards ZIP. No Python installation is needed to play, run the Global Bank helper, or use the extension.

1. Install the full Cherry's Kit into your game's Interface\AddOns folder. Check that Interface\AddOns\CherrysKit\CherrysKit.toc exists.
2. Extract the Daily Rewards ZIP into that same Interface\AddOns folder and agree to merge CherrysKit. Do not extract a GitHub Source code ZIP: that is not an installer. The Daily Rewards files end up in Interface\AddOns\CherrysKit\GlobalBank\Helper.
3. Open that Helper folder in File Explorer. Double-click Install Chrome extension.bat. Its window stays open and shows the bridge registration, the exact extension folder path, and the one-time Chrome steps. It tries to copy the folder path and open chrome://extensions/ in Chrome.
4. In Chrome, turn on Developer mode at the top right. Click Load unpacked at the top left.
5. In the folder picker press Alt+D to focus the address bar. Press Ctrl+V to paste the path the installer copied, then press Enter. If copying failed, type the extension folder path printed in the installer window instead. Click Select Folder. The picker selects folders, so an empty-looking file list is normal; do not search for the extension there.
6. Confirm that Global Bank Daily Rewards appears in Chrome and is enabled. If the extensions page did not open, double-click Open Chrome extensions.bat in the Helper folder, or type chrome://extensions/ into Chrome's address bar.
7. Double-click Start Global Bank helper.bat in the Helper folder. Keep its window open and log in to each character so the helper can build current snapshots. For the record to be saved, the displayed character must match one unambiguous level 100 snapshot.
8. In game open the daily loyalty page through ZShop using Chrome. If a reward is available, the extension tries to collect it and records the result locally after Gameforge confirms collection. Click the extension icon for status. When the helper is stopped, the page can offer to start it.

The extension is not currently on the Chrome Web Store. Windows PowerShell is used for the local bridge; setup registers it for your current Windows user. The installer does not store your Gameforge password.

PRIVACY: Automatic page processing runs only on the Gameforge daily shop page. The extension reads the displayed character name, server and reward state there. Temporary extension status is held in Chrome session storage. The local bridge writes confirmed character, server, day and time to Interface\GlobalBankHelper\DailyRewards.json. The extension does not send these details to the developer or another third party; collecting interacts with Gameforge. The separate GlobalBank.json contains inventory data; keep the GlobalBankHelper folder private.

This is an independent community tool, not an official Gameforge extension. If collection or local recording fails, check the page and the extension status; refresh your character snapshot by logging in and running the helper.
