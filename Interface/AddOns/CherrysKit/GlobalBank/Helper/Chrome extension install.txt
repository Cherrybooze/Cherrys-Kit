Global Bank Daily Rewards - Windows + Google Chrome installation

YOU NEED: Cherry's Kit with Global Bank, Google Chrome, and the separate Daily Rewards ZIP. No Python installation is needed to play, run the Global Bank helper, or use the extension.

1. Install the full Cherry's Kit into your game's Interface\AddOns folder. Check that Interface\AddOns\CherrysKit\CherrysKit.toc exists.
2. Extract the Daily Rewards ZIP into that same Interface\AddOns folder and agree to merge CherrysKit. Do not extract a GitHub Source code ZIP: that is not an installer. The Daily Rewards files end up in Interface\AddOns\CherrysKit\GlobalBank\Helper.
3. Open that Helper folder in File Explorer. Double-click Install Chrome extension.bat. It registers the local bridge and brings up Chrome's extensions page, with a small setup window on top.
4. In Chrome, turn on Developer mode at the top right, then click Load unpacked at the top left. Those two clicks are all Chrome needs: the setup window fills in the folder and closes when the extension connects.
5. If the folder window does not fill itself in, the setup window copies the path for you: press Ctrl+V in the folder window, then Enter. If the extensions page did not open, type chrome://extensions/ into Chrome's address bar.
6. Confirm that Global Bank Daily Rewards appears in Chrome and is enabled. For this page later, double-click Open Chrome extensions.bat in the Helper folder.
7. Double-click Start Global Bank helper.bat in the Helper folder. Keep its window open and log in to each character so the helper can build current snapshots. For the record to be saved, the displayed character must match one unambiguous level 100 snapshot.
8. In game open the daily loyalty page through ZShop using Chrome. If a reward is available, the extension tries to collect it and records the result locally after Gameforge confirms collection. Click the extension icon for status. When the helper is stopped, the page can offer to start it.

LOCAL BANK AND AUCTION TOOLS: Click the extension icon in Chrome, then Open local bank and auction tools. The Bank tab shows everything your characters hold in one grid, with a search and filters; hover an item to see who has it and in which slot. Update now reads your save files. The Terminal tab runs the helper's commands, including note and erase; type help for the list. The Auctions tab searches saved auction results, which may have changed. You only need the helper window for collecting auction data and for automatic updates each time you log out. Nothing on the page can buy items.

UPGRADING: Extract the new ZIP over the old files, run the installer again, and click the reload icon on the extension card at chrome://extensions/.

The extension is not currently on the Chrome Web Store. Windows PowerShell is used for the local bridge; setup registers it for your current Windows user. The installer does not store your Gameforge password.

PRIVACY: Automatic page processing runs only on the Gameforge daily shop page. The extension reads the displayed character name, server and reward state there. Temporary extension status is held in Chrome session storage. The local bridge writes confirmed character, server, day and time to Interface\GlobalBankHelper\DailyRewards.json. Whenever Chrome starts or the extension contacts it, the bridge also writes Windows' time to Interface\GlobalBankHelper\CherrysClockStamp.lua so addons can show the real time; that file stays on your PC. The extension does not send these details to the developer or another third party; collecting interacts with Gameforge. The separate GlobalBank.json contains inventory data; keep the GlobalBankHelper folder private.

This is an independent community tool, not an official Gameforge extension. If collection or local recording fails, check the page and the extension status; refresh your character snapshot by logging in and running the helper.

UPDATING: After replacing the installed extension files, click the extension icon and choose Reload extension. If your older copy does not have that button, use Reload on its card in chrome://extensions once. Reopen the popup or local tools page afterwards. Reloading uses files already installed; it does not download an update.

AUCTION CACHE (version 1.0.7 or later): Choose Show whole cache to browse saved auctions, or search by name, item ID or named stat. Select a stat and optional minimum or maximum to filter; sort by name, level, tier, durability, selected stat, estimated end or buyout. End times are estimates from the game's rounded remaining time. Old entries can lack durability and stats; search again in game and let the helper import the results. These are saved observations, not live listings.
